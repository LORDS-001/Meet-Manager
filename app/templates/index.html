How do I connect my real Google Calendar?
  1. Open Google Cloud Console → Credentials.
  2. Enable the Google Calendar API for your project.
  3. Create an OAuth client ID of type Web application.
  4. Add this exact authorised redirect URI: http://127.0.0.1:8000/auth/callback
  5. Under OAuth consent screen → Test users, add {{ owner_email }}.
  6. Copy the client ID and secret into the .env file, then restart the app.
